# 执行日志格式

每任务在 `run_records` 记录：

1. 任务元数据、图片1/图片2路径及固定上传顺序。
2. 输入像素、格式、可读性和异常。
3. 产品保护清单、包装拓扑白名单、空区、碰撞排除、光影边界和核心可见区。
4. 构图锁、`pose_mode`、长轴与端点锚点、俯仰/偏航/滚转、主体占比、视觉质量、KEY场景结构、人物/道具、邻接细节和多商品一致性。
5. 生成前竞争视觉策略：风格标签与证据、0.3秒路径、最强钩子、钩子保留计划、缩略图前三元素、七类风险矩阵和P0–P3优化队列。
6. 用户确认的替换、删除、原样保留及删除闭环。
7. 产品色板、每个可变元素的 `hue_family / luminance_role / saturation_role`、最终亮色、对比和视觉优先级。
8. `luminance_region_map`：每区坐标、参考与候选的 `mean_luma / p50_luma / p90_luma / dark_ratio`、差值、分级阈值、`PASSED / PASSED_WITH_NOTES / REVIEW_REQUIRED / REJECTED`、人工复核依据、`qa_python`与`qa_duration_ms`；保留 `luminance-qa.json`。
9. Prompt 使用身份优先或构图主导、亮度锁与产品光影锁是否位于前30%、最高风险前置、字符数、UTF-8回读和排除项。
10. 生成配置、submit_id、状态、积分、下载路径和 attempt。
11. QA：产品身份、包装拓扑、构图骨架、姿态类别、长轴偏差、锚点、视觉质量偏差、KEY场景结构、核心文案、KEY邻接细节、手部、明亮度和视觉层级的 `PASSED / NOTE / REVIEW_REQUIRED / REJECTED` 证据；所有`REVIEW_REQUIRED`必须记录最终人工裁决。
12. 生成后竞争视觉复盘：实际风格偏移、实际0.3秒路径、缩略图前三元素、钩子结果及七类`✅ / ⚠️ / ❌`细节表。
13. 重试差异、`retry_trigger`、亮度重试计数、停止原因和最终选中图片。

批次汇总任务数、通过/提示/拒绝、总尝试次数、实际积分、余额和输出路径。

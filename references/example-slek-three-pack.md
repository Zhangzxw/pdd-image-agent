# 舒蕾三瓶装参考范式

本例用于学习“反推深度与执行顺序”，不能作为所有商品的硬编码内容。

## 步骤1：目标效果图反推

- 1:1 电商大促主图；右中区域为三瓶等距蓝色喷雾，左上品牌，顶部巨型标题，左侧数量胶囊与金色徽章，底部蓝紫渐变通栏。
- 精确画外文字：左上“SLEK 舒蕾”；顶部“速杀害虫 无色无味”；蓝色胶囊“3瓶装”；金色徽章“长效守护”；底部“传染死亡 虫卵双杀”。
- 背景为浅薄荷绿明亮厨房，白色石英台面，三只 Q 版倒地蟑螂，瓶周有半透明浅蓝波纹。
- 风格为拼多多/京东囤货爆品主图，半写实 3D 产品渲染与真实治愈厨房融合。
- 光线为窗边白日柔和漫射光；瓶身有通透蓝色高光，台面有浅倒影和软接触阴影。

## 步骤2：Prompt 组装

先写画布与商业风格，再锁定三瓶产品排列和产品事实，逐字写入五个画外文字区域，随后写厨房、台面、蟑螂、波纹、配色、光线、材质、景深、2K 和负面约束。覆盖表确认每个目标元素均已进入 Prompt。

## 步骤3：生成

仅上传单瓶产品事实图，固定 `dreamina image2image / 5.0Pro / 1:1 / 2k / 1张`。目标效果图不上传，它的视觉信息通过 Prompt 注入。

## 步骤4：QA

阻断检查：三瓶数量与排列、品牌和主包装信息、五个核心画外文字区域、薄荷绿厨房和蓝色波纹。微型包装说明若无法稳定生成则记录为提示项，不掩盖宏观合格结果。

# 目标图文字与产品事实映射

1. 为目标效果图中每个文字区域分配唯一 ID，并逐字记录文字、数字、标点、换行、位置、层级、字体类别、字号、字重、颜色、渐变、描边、阴影和容器形状。
2. Logo、标题、副标题、数量标签、徽章、角标和底部通栏不得合并概括。
3. 默认原样复刻所有画外促销与营销文字；不得根据产品类别自动重写、删减或“优化”。
4. 目标图中的产品包装只用于理解版式，不得覆盖 `ProductImage` 的真实产品事实。
5. 产品外形、品牌、产品名、主要参数、净含量、主图案和可辨识主印刷信息以 `ProductImage` 为准。
6. 如目标图含与产品事实图明确不同的第三方商标、店铺名、价格、认证、赠品或规格，必须在分析中标记冲突；未经用户确认不得伪造事实。
7. Prompt 中所有精确文字使用中文引号，并保留区域和样式描述。
8. QA 区分核心画外文字与微型包装字：核心文字错误是阻断项；无法可靠辨认的微型字仅作为提示项。
9. 文案内容、字体类别、字号层级、字重、行数、换行、字距、对齐、描边宽度、阴影方向和容器结构全部锁定；不得借“配色优化”改变。
10. 仅按产品色板替换画外文字的填充色、描边色和阴影色。每个文字 ID 都必须记录原色、映射色和产品取样来源。

# 竞品双参考高精度模式

## 输入权威

- 固定上传两张图：图片1为 `ProductImage/00_` 主产品图，图片2为当前任务对应的 `EnterImage` 竞品图。
- 图片1是包装、Logo、品名、规格、结构、主色、材质和原生文字的唯一产品身份母版。
- 图片2是画布、场景、人物、画外文字槽位、产品数量、二维位置、重叠、底栏和视觉阅读顺序的构图母版；竞品包装不是产品事实。
- 禁止反转图片顺序。禁止上传产品详情图；详情图只供本地核对。

## Prompt 结构

Prompt 首段写入 `[DUAL_REFERENCE_AUTHORITY]`，明确图片1锁产品身份、图片2锁二维构图。随后按以下顺序组织：

1. `[PRODUCT_IDENTITY_LOCK]` 与保护文字清单。
2. `[PIXEL_COMPOSITION_GUIDE]`：用百分比记录产品组、标题、人物、徽章和底栏，但声明为高优先级视觉引导，不是假定模型能逐像素冻结。
3. 产品数量、同母版、前后层级、重叠和核心可见区。
4. KEY邻接细节、完整冲突映射与全部原样保留文案。
5. 场景、字体、限定配色适配和精简竞品排除项。

不得使用“固定像素层”“除产品外像素不变”等模型无法兑现的伪蒙版指令。不得反转参考图顺序来追求构图。

## 默认限定配色适配

在保持图2构图骨架、坐标、占比、轮廓、材质、纹理、光源方向、明暗层级和渐变结构的前提下，默认把以下颜色映射到图片1产品色板：

- 背景：只调整背景主色家族、冷暖和既有渐变色值；天空、墙面、台面、草地等空间类型、边界、纹理、景深和光影结构不变。
- 画外文字：只调整填充、描边和阴影颜色；字体、字号、字重、换行、位置和层级不变。
- 横幅/底栏：只调整填充、边框和原有渐变颜色；轮廓、尺寸、圆角、左右分区、材质、渐变方向和停靠点结构不变。
- 徽章/勋章：只调整主体色、强调色、描边色和高光色；轮廓、图标、尺寸、位置、材质、压印和层级不变。

目标产品包装必须保持图片1原色，不受背景暖色/冷色统一滤镜影响。人物肤色、道具本色、泡沫、水体、矿石和其他 KEY 邻接细节不因配色适配而改成产品色。用户明确要求完全保留竞品原配色时关闭本节。

## 宽容构图 QA

像素测量用于比较、记录和下一轮 Prompt 引导，不作为逐坐标硬验收。首轮结果满足以下条件即可进入最终输出，通常标记为 `PASSED_WITH_NOTES`：

- 产品品牌、品名、规格、主色、包装主图案和结构保持为目标产品；没有明显竞品包装回流。
- 产品数量正确，多产品保持同款；没有严重拉伸、弯曲、透视重建或核心 Logo/品名不可辨。
- 主标题、核心数字、用户确认后的替换文案和必须原样保留的核心声明内容正确且可读。
- 整体构图骨架一致：标题仍在同一主要象限，商品组仍在同一主要区域，人物/道具仍承担相同视觉角色，底栏仍位于底部并保持横向通栏或原有主要形态，阅读顺序未颠倒。
- 关键泡沫、矿石、水面、人物或其他 KEY 邻接细节没有完全缺失或被错误材质替代。

下列差异只记 `NOTE`，不自动重试：

- 产品顶部、底部、宽度、间隙、重叠率与参考图存在小到中等偏差，但商品仍位于正确区域且画面协调。
- 底栏顶边、底栏高度、标题字号、行高、左右留白或徽章尺寸发生小到中等变化，但底栏仍横跨底部主要宽度，标题层级和信息结构仍清楚。
- 商品组仍在正确主要区域且主次关系未改变时，前件没有完全触及参考图边界、左右留白偏大或商品组宽度存在小到中等差异。
- 人物、泡沫、散景、草地、水面或背景道具的局部位置、密度、形状变化。
- 包装中源图本就难辨的微型文字和画外非核心微型英文轻微近似。
- 为保护产品文字清晰而自然降低二维倾角。

只有以下硬失败才标记 `REJECTED` 并触发自动重试：

- 目标产品被换色、换包装、换Logo、换品名/规格，或出现显著竞品品牌、标签、主色和包装结构回流。
- 商品数量错误、缺失核心商品、多产品不是同款，或产品严重变形、三维视角重建。
- 用户确认的核心替换文案、必须保留的核心声明、主标题或核心数字出现明显错漏、串位或不可读。
- 整体构图骨架改变：商品组跨到错误半区、标题与商品主次颠倒、底栏不再位于底部或从横向通栏变成局部侧框、人物/关键场景完全缺失。
- KEY邻接细节完全缺失、手部明显畸形，或关键元素错误遮挡Logo、品名和规格。
- 生成失败、登录/合规/余额/参数异常。

## 重试策略

- NOTE 不重试，首轮直接选入最终输出。
- 仅硬失败重试，每任务最多2次；只强化失败项，同时完整重申产品身份、冲突映射和整体构图骨架。
- 不因坐标、边界贴合、左右留白、底栏高度、徽章尺寸或字号比例差异单独重试。只有商品组跨到错误半区、主次颠倒或大面积空洞破坏原阅读路径时，才升级为构图骨架硬失败。
- 每轮仍记录参考与结果的量化差异，供后续优化 Agent 使用。

# 竞品双参考高精度模式

## 输入权威

- 图片1=`ProductImage/00_`：唯一产品身份母版。
- 图片2=当前竞品图：构图、展示姿态、场景、人物、画外文字槽位、主体数量、位置、重叠、底栏和阅读顺序母版；不提供包装事实。
- 顺序不得反转；产品详情图只供本地核对，不上传。

## Prompt

普通正面、近正面和只需平面滚转的任务依次写：双参考权威 → 产品身份与几何保真锁 → 当前最高风险 → 构图。横置本身不自动等于三维；标签仍正对镜头且无可见侧面时继续用 `rigid_2d`。只有倾倒、开瓶、明显俯仰/偏航、强透视、可见侧面、复杂遮挡或历史构图漂移任务才使用：双参考权威 → 构图主导段 → 精简产品身份与几何锁 → 当前最高风险。两类任务都必须在前30%写入几何、姿态、视觉质量和KEY场景结构，之后再写邻接细节、冲突映射、删除闭环、全部文案、场景/字体、有限色彩适配和精简排除项。

主体边界框只能控制整件商品的等比缩放和平移。图片1与图片2瓶型差异大时，优先保持目标整体宽高比、瓶盖/泵头、瓶颈、肩部、标签、液位和瓶底比例；允许牺牲精确倾角、透视或少量满版占比。产品几何形变的两级自动降级为：`controlled_3d_pose → rigid_2d完整几何量化 → 5°–10°低倾角零形变锁`。

包装碰撞必须首轮闭环：竞品显著包装元素不在目标白名单时，既写入正向目标区域描述，也写入反向排除；保护空区保持空白、纯色或连续纹理。

## 明亮配色

- 背景默认保持竞品的色相、饱和度、明度分区与空间纵深；只有用户确认允许时，画外文字、横幅/底栏、徽章/勋章及指定背景区域才有限映射到产品色板。
- 背景浅亮通透；标题用亮红、亮蓝、白色或其他明亮阶，可配清晰描边、荧光边缘或电镀高光；横幅与徽章使用亮色主体。
- 深色仅作小面积描边、分隔和必要对比。人物、道具、邻接细节和产品包装保持本色。
- 视觉优先级：主产品/主标题/次标题 > 横幅/徽章 > 背景。

## 宽容 QA

产品身份、包装拓扑、目标几何比例、用户确认文案、商品数量、姿态类别、构图骨架、视觉质量、KEY场景结构、KEY邻接细节和视觉层级为硬约束。长轴约6°–15°、视觉质量约10%–20%及中小幅坐标、字号、留白、边界、间隙、底栏高度、徽章尺寸和微型文字差异记 `NOTE`；但整体/瓶盖比例、瓶颈、肩部、标签、液位、瓶底或关键平行线明显漂移不得记NOTE。只有硬失败重试，每任务最多2次。

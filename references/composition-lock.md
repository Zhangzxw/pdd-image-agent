# 竞品构图锁

## 边界

从 `EnterImage` 复刻商品数量、边界框、展示大小、姿态与透视、视觉质量、留白、层级、遮挡、接触关系和阅读路径；竞品品牌、标签、包装图案和与目标冲突的物理结构不可迁移。目标产品身份与基本几何始终以 `00_` 为准；竞品只定义其在成图中应达到的姿态与空间关系。

构图类型只是分析标签，不能代替坐标。不得因画布为 1:1 自动采用中心或对称构图，不得用“主体40%–60%”“必须留白”“最多三色”等通用设计建议覆盖目标图事实。

## 必填结构

建立 `composition_lock`：

1. `composition_archetype`：主/辅助构图类型、对称性、构图轴、文字与商品关系。
2. `visual_mass_map`：产品组、标题、人物、徽章、底栏和关键道具的视觉重量及平衡关系。
3. `negative_space_map`：标题安全区、商品区、徽章区、底栏区、最大留白区和禁止出现空洞的区域。
4. `composition_anchor_lines`：产品中轴/底线、标题边缘、徽章对齐轴、通栏顶边及显著对角引导线。
5. `visual_flow_path`：按实际目标图记录第一至第五视觉落点；辅助元素不得抢占第一落点。
6. `occlusion_graph`：用 `A > B` 表示 A 位于 B 上层并允许遮挡，用 `A !> B` 表示禁止遮挡；不得统一假定所有文字都在产品上层。
7. `depth_layers`：背景、后景、后排商品、前排商品、前景邻接细节和画外叠加层。
8. `product_pose_lock`：逐件记录长轴起点/终点、角度与象限、瓶口/瓶盖锚点、底端锚点、标签中心方向、俯仰/偏航/滚转估计、关键交点和遮挡关系。
9. `visual_mass_lock`：记录轮廓面积、不透明或高对比标签面积、亮暗质量中心；透明产品不得因轮廓显轻而自动放大。
10. `critical_scene_structure_lock`：记录分隔线、矩形框、仪器底座、管线路径、小图标、平台和承托物等KEY结构的坐标、色值、层级和相互关系。

## 量化分级

- A级必须量化：逐件/商品组边界框、标题区、底栏、核心徽章、产品间隙/重叠、核心可见区。
- B级建议量化：人物、手部、KEY泡沫、主要矿石和大型道具。
- C级只描述关系：零散气泡、花瓣、微粒、散景和轻微光点。

坐标和面积是视觉区间，不是几何渲染器合同；避免无意义的过度精确和相互冲突。产品宽度始终服从真实宽高比。

边界框、占比和“撑满”都只能驱动整件商品的等比缩放、平移和已判定的姿态变换，不能驱动局部几何重塑。若目标产品与竞品瓶型不同，允许在参考主体区内部产生少量留白或轮廓差异；禁止拉宽、拉高、压扁瓶盖、拉长瓶颈、改变肩宽、移动液位、增减标签高度或用梯形透视填满竞品边界。构图相似度不得凌驾于目标产品几何保真。

## Prompt 固定段

`[COMPOSITION_LOCK] 按已量化的构图关系组织画面，不因正方形画布自动居中或对称。逐项保持商品组、标题区、徽章区、人物/道具区和底栏区的边界、姿态长轴、端点锚点、视觉重量、留白、锚线、前后层级、遮挡关系、关键结构与阅读顺序。辅助道具不得成为第一主体；不得为文案腾位而静默缩小商品；不得以更符合通用设计原则为由改变目标构图。`

紧接固定段写入任务实际的 `composition_archetype / visual_mass_map / negative_space_map / composition_anchor_lines / visual_flow_path / occlusion_graph / depth_layers`。

## QA

以下任一情况为 `REJECTED`：

- 构图类型或文字-产品关系明显改变。
- 商品组、标题区或底栏区跨越主要目标区域。
- 产品占比正确但视觉质量、留白或阅读顺序明显跑偏。
- 本应在后层的元素错误遮挡核心产品或文案。
- 以中心、对称、极简留白等通用构图替代目标实际构图。
- 商品姿态类别错误、长轴落入错误象限，或瓶口/底端锚点与关键交点明显跑位。
- 轮廓边界看似接近但视觉质量中心明显偏移，或KEY分隔线、框架、管线、仪器底座等关键结构缺失。

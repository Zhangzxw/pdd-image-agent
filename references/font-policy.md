# 画外字体硬约束

## 适用范围

- “画外文字”包括画面中新生成的标题、副标题、数字、百分比、徽章、角标、标签、按钮、说明、底部通栏、店铺名和画外 Logo 文字。
- 产品包装上由 `ProductImage` 带入的原生品牌、品名、参数、说明和 Logo 字体属于产品身份，不计入画外字体数量；不得为了满足字体限制而重排、替换或统一包装原生字体。
- 道具上原本不可辨认的微型装饰字符只按低对比图形处理，不主动改写成可读文字，也不计为新增字体。

## 硬规则

1. 每张成图默认使用 1 种画外字体，最多使用 2 种字体。超过 2 种即 `REJECTED`，不得以“接近参考图”或“装饰需要”为理由放宽。
2. 画外中文、数字、标点和常规拉丁字符首选拼多多正黑体（PDDZHT）。
3. Dreamina 无法准确调用 PDDZHT 时，使用“拼多多正黑体风格的粗黑无衬线体”：粗壮、端正、紧凑、高识别度、无书法笔触、无宋体衬线、无手写感。
4. 第二种字体仅在目标图确有重要且可见的第二字体层级时使用，例如微型英文、数字徽章或强调短语；不需要时整张图只使用一种画外字体。
5. 字重、字号、描边、阴影、倾斜、压缩、换行和颜色不视为新的字体家族，但不得借样式变化制造明显的第三种字体观感。

## 分析与 Prompt

- 分析文件单独列出 `external_font_inventory`，逐项记录画外文字区域、指定字体、用途和是否计入字体数量。
- Prompt 必须包含等价约束：`全部画外文字最多使用2种字体；首选拼多多正黑体PDDZHT；无法准确调用时使用拼多多正黑体风格的粗黑无衬线体；产品包装原生字体不计入画外字体数量且保持不变。`
- Prompt 中出现书法体、宋体、手写体等目标字体时，只有用户明确要求保留且总数仍不超过2种才允许；否则统一映射为 PDDZHT 或其粗黑无衬线回退。

## QA 与重试

- QA 只统计画外字体家族，不统计包装原生字体。
- 画外字体数量为 1 或 2，且主要中文使用 PDDZHT 或规定回退风格：字体项 `PASSED`。
- 画外字体超过 2 种、出现未经要求的书法/宋体/手写字体，或主要中文未使用 PDDZHT/规定回退风格：字体项 `REJECTED`。
- 字体失败重试时只修改字体相关 Prompt 片段，锁定已正确的产品、文案、构图、人物、场景、颜色和光影。

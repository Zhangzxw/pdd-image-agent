# 目标效果图像素级全维度反向解构

将 `EnterImage` 视为目标成图，不是模糊风格参考。按下列顺序输出，并区分“画面可见事实 / 合理推断 / 无法确认”。

## 1. 画布与主体

- 原图像素、比例、裁切、留白和安全区。
- 每个商品的数量、边界框百分比、大小、间距、层级、遮挡、朝向、透视、底线和占画面比例。
- 全部人物、动物、害虫、道具、图标、波纹、粒子、倒影、阴影和装饰。
- 背景空间类型，以及每个可见软装、家具和环境细节。

## 2. 全量文字

- 为 Logo、标题、副标题、数量标签、徽章、角标、底部通栏和包装主文字分配唯一 ID。
- 逐字记录文字、数字、标点、换行、方向、位置、字号层级、字体风格、颜色、渐变、描边、阴影和容器形状。
- 记录文字与产品、道具、边缘之间的相对距离。

## 3. 风格与商业逻辑

- 平台、活动类型、类目、商业摄影/3D渲染/插画比例。
- 情绪、氛围、消费心智、高转化卖点和一秒阅读顺序。
- 技法关键词、后期锐化、柔光、调色、边缘处理和广告完成度。

## 4. 配色

- 主色、辅色、背景滤镜、渐变、徽章色、文字色。
- 每种颜色的建议 HEX、覆盖比例、明度、饱和度、冷暖和色彩对比关系。
- 分开输出“目标图原配色”和“产品包装色板”，不得把目标图旧产品颜色当作新产品配色依据。
- 产品包装色板至少记录：主色、辅色、强调色、中性色、各颜色来源区域、建议 HEX、覆盖比例和置信度。
- 透明/白色产品优先从标签、瓶盖、Logo、主图案取色，不把透明背景或白底误判为包装主色。
- 建立颜色映射表：仅覆盖画外文字填充/描边/阴影和底部框体填充/边框/原有渐变颜色。

## 5. 光影与镜头

- 主光/辅光方向、光源类型、色温、硬软程度、曝光与动态范围。
- 商品高光、轮廓光、接触阴影、台面倒影和背景明暗层级。
- 机位高度、俯仰角、左右视角、焦段感、透视、景深和焦点位置。

## 6. 构图与材质

- 视觉重心、黄金区域、主体/文字占比、元素坐标区间和层级关系。
- 产品、台面、家具、纸张、金属、塑料、玻璃、徽章、光效的透明度、粗糙度、反射和边缘锐度。
- 按 [composition-lock.md](composition-lock.md) 建立 `composition_archetype / visual_mass_map / negative_space_map / composition_anchor_lines / visual_flow_path / occlusion_graph / depth_layers`。竞品物理包装结构不可复刻；只提取其二维构图关系。

## 7. 产品事实图锁定

单独检查 `ProductImage`，记录产品轮廓、比例、颜色、材质、品牌、产品名、主要参数、净含量、包装主图案及可辨识主印刷信息。目标图中的产品包装不得覆盖这些事实。

产品本体颜色和包装颜色属于绝对锁定项，禁止为了“统一配色”对产品调色、换色、套滤镜或改变透明度。

按 [product-identity-lock.md](product-identity-lock.md) 建立 `protected_texts / protected_logo / geometry_anchor / material_anchor / viewpoint_anchor / product_pose_guide`，同时建立 `image2image_source_authority / lighting_application_boundary / core_visibility_zone`。`protected_texts` 必须逐字记录可辨认原文、数字、标点和换行；`protected_logo` 同时记录核心视觉特征词；`material_anchor` 明确包装主体底色、材质本色和表面质感。微型不可辨文字只记录位置、行数、颜色与印刷密度。允许的产品变换为：整体等比例缩放、平移、有边界的自然光影融合，以及不改变源图观察视角的刚性二维平面旋转。

`product_pose_guide` 从目标效果图记录：二维倾斜方向与建议角度区间、展示级别、产品高度占比区间、中心区域、顶部/底部位置、遮挡和接触关系。以上参数用于构图引导，不是像素级硬门槛；产品宽度必须服从 `geometry_anchor` 的真实宽高比，不得为了匹配竞品边界框而独立拉伸或压缩。

## 7.1 主体占比锁

建立 `subject_occupancy_lock`，按每件参考商品记录：`商品ID / left% / top% / right% / bottom% / 宽度% / 高度% / 边界框面积% / 可见面积估计% / 是否出框 / 出框方向与幅度% / 前后层级`。多商品另记录：`商品总面积占比% / 最小可见间隙% / 最大可见间隙% / 重叠率% / 中心距% / 前件遮挡后件比例%`。

- 默认用参考商品的顶部、底部、宽度和总占画面积约束生成主体；不得只记录中心点或“偏大/偏小”。
- 边界框与面积是柔性视觉区间，但生成 Prompt 必须写出明确百分比，不得概括成“与参考图大小一致”。
- 用户说“撑满”“放大主体”“产品和参考一样大”“紧凑靠一起”时启用 `full_bleed_mode=true`：商品建议高度 `95%–110%`，允许顶部或底部轻微出框，双商品可见间隙建议 `0%–2%`，按参考图记录必要重叠率。
- 满版模式仍服从 `geometry_anchor`：宽度由真实宽高比和整体等比缩放自然得到；禁止独立拉宽、拉高、压扁或改变三维视角。
- 若满版占比与文字区冲突，先按参考图的前后遮挡和出框关系解决，不得静默缩小商品或改写版式。

## 7.2 产品邻接细节扫描

建立 `product_adjacent_detail_inventory`。对每件产品按“顶部 → 左轮廓 → 右轮廓 → 瓶底/落点 → 接触面 → 前景遮挡 → 后景衬托”顺序逐区检查，不得只描述背景大类。

逐项记录：`细节ID / 类型 / 准确材质语义 / source_class / transfer_policy / 相对产品区域 / 坐标% / 覆盖范围 / 颜色与透明度 / 颗粒或泡孔尺度 / 密度 / 边缘形态 / 前后层级 / 与产品接触或遮挡关系 / 商业作用 / 显著度 / Prompt片段`。

`source_class` 使用 `external_scene_detail / product_surface_effect / competitor_packaging_content`；`transfer_policy` 使用 `KEEP / KEEP_WITH_BOUNDARY / REJECT`。竞品包装原生文字、纹理、标签、品牌色和印刷图案一律为 `competitor_packaging_content + REJECT`，不得伪装成邻接细节。

重点识别泡沫、泡孔、膏体、水珠、水花、液膜、粉末、矿石、颗粒、花瓣、烟雾、蒸汽、光圈、辉光、倒影和接触阴影。必须进行语义分离，例如：

- 绵密泡沫不是白毛巾、白云、雾气、曝光高光或普通阴影。
- 水珠不是包装印刷圆点或背景散景。
- 接触阴影、倒影和液体反射分别记录，不得合并成“自然光影”。

显著度分级：

- `KEY`：面积明显，贴近或环绕产品，承担产品落地、遮挡、卖点表达、动势或主要商业质感；缺失会显著改变目标效果。
- `SUPPORTING`：可见但不支配构图，强化材质和氛围。
- `MICRO`：零散小水珠、少量气泡或微粒，形状与数量无需机械一致。

只要目标图可见，就必须进入元素覆盖表；`KEY` 项必须独立写入 Prompt，不得被“场景自然融合”“毛巾背景”等概括词吞并。

## 8. 不可变项矩阵

逐项记录并锁定：画布比例；所有元素坐标与占比；文案文字、数字、标点与换行；字体类别、字号层级、字重、倾斜、描边宽度与阴影方向；容器形状、尺寸、位置、圆角、分区和层级；场景、人物/动物、道具、图标和特效；产品数量、外形、颜色、包装和印刷信息。

只有下列颜色属性可变：

- 画外文字：填充色、描边色、阴影色。
- 底部框体/通栏：填充色、边框色；原图已有渐变时可替换渐变色，但方向、停靠点数量和结构不变。

建立 `layout_regression_lock`：逐项列出标题文字、填充色、描边色、阴影、字体、字号层级、标签底框、图标类型与数量、宣传文案、容器形状和底部框体。每个框体同时记录实际存在的正向属性及差分负向约束；不得对所有框体统一套用“无圆角、无描边、无阴影”。另记录每个文字区与产品的真实层级关系，不得统一假定全部文字位于产品上层。只要后续修改产品大小、位置、间隙、重叠或出框程度，必须把该清单完整写回新 Prompt；禁止用“保持上一轮不变”代替。

## 9. 元素覆盖表

使用列：`元素ID / 可见内容 / 类型 / 区域与坐标% / 尺寸占比 / 颜色 / 材质 / 层级 / 置信度 / Prompt片段 / 是否覆盖`。产品邻接细节必须从 `product_adjacent_detail_inventory` 逐项进入覆盖表；未覆盖项必须补齐后才能生成。

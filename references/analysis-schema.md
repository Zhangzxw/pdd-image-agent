# 目标效果图像素级全维度反向解构

将 `EnterImage` 视为目标成图，不是模糊风格参考。按下列顺序输出，并区分“画面可见事实 / 合理推断 / 无法确认”。

## 1. 画布与主体

- 原图像素、比例、裁切、留白和安全区。
- 每个商品的数量、边界框百分比、大小、间距、层级、遮挡、朝向、透视、底线和占画面比例。
- 全部人物、动物、害虫、道具、图标、波纹、粒子、倒影、阴影和装饰。
- 背景空间类型，以及每个可见软装、家具和环境细节。

## 2. 全量文字

- 为 Logo、标题、副标题、数量标签、徽章、角标、底部通栏和包装主文字分配唯一 ID。
- 逐字记录文字、数字、标点、换行、方向、位置、字号层级、字体风格、颜色、渐变、描边、阴影和容器形状。
- 记录文字与产品、道具、边缘之间的相对距离。

## 3. 风格与商业逻辑

- 平台、活动类型、类目、商业摄影/3D渲染/插画比例。
- 情绪、氛围、消费心智、高转化卖点和一秒阅读顺序。
- 技法关键词、后期锐化、柔光、调色、边缘处理和广告完成度。

## 4. 配色

- 主色、辅色、背景滤镜、渐变、徽章色、文字色。
- 每种颜色的建议 HEX、覆盖比例、明度、饱和度、冷暖和色彩对比关系。
- 分开输出“目标图原配色”和“产品包装色板”，不得把目标图旧产品颜色当作新产品配色依据。
- 产品包装色板至少记录：主色、辅色、强调色、中性色、各颜色来源区域、建议 HEX、覆盖比例和置信度。
- 透明/白色产品优先从标签、瓶盖、Logo、主图案取色，不把透明背景或白底误判为包装主色。
- 建立颜色映射表：仅覆盖画外文字填充/描边/阴影和底部框体填充/边框/原有渐变颜色。

## 5. 光影与镜头

- 主光/辅光方向、光源类型、色温、硬软程度、曝光与动态范围。
- 商品高光、轮廓光、接触阴影、台面倒影和背景明暗层级。
- 机位高度、俯仰角、左右视角、焦段感、透视、景深和焦点位置。

## 6. 构图与材质

- 视觉重心、黄金区域、主体/文字占比、元素坐标区间和层级关系。
- 产品、台面、家具、纸张、金属、塑料、玻璃、徽章、光效的透明度、粗糙度、反射和边缘锐度。

## 7. 产品事实图锁定

单独检查 `ProductImage`，记录产品轮廓、比例、颜色、材质、品牌、产品名、主要参数、净含量、包装主图案及可辨识主印刷信息。目标图中的产品包装不得覆盖这些事实。

产品本体颜色和包装颜色属于绝对锁定项，禁止为了“统一配色”对产品调色、换色、套滤镜或改变透明度。

## 8. 不可变项矩阵

逐项记录并锁定：画布比例；所有元素坐标与占比；文案文字、数字、标点与换行；字体类别、字号层级、字重、倾斜、描边宽度与阴影方向；容器形状、尺寸、位置、圆角、分区和层级；场景、人物/动物、道具、图标和特效；产品数量、外形、颜色、包装和印刷信息。

只有下列颜色属性可变：

- 画外文字：填充色、描边色、阴影色。
- 底部框体/通栏：填充色、边框色；原图已有渐变时可替换渐变色，但方向、停靠点数量和结构不变。

## 9. 元素覆盖表

使用列：`元素ID / 可见内容 / 类型 / 区域与坐标% / 尺寸占比 / 颜色 / 材质 / 层级 / 置信度 / Prompt片段 / 是否覆盖`。未覆盖项必须补齐后才能生成。

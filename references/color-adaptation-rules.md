# 明亮色相适配与视觉层级

默认保持竞品背景的色相、饱和度、明度分区和空间纵深。仅在用户确认允许适配时，才改变指定背景区域的色相、画外文字填充/描边/光效颜色、横幅/底栏填充与边框颜色、徽章/勋章主体色与高光色。不得改变构图、位置、尺寸、形状、材质、纹理、光源方向、渐变结构、人物肤色、道具本色、邻接细节或产品包装原色。

## 固定闭环

严格按以下顺序执行，不得省略或改为主观判断：

1. 从参考图建立 `luminance_region_map`，取得全图、背景、产品、标题、横幅、徽章和底栏的基准亮度。
2. 在 Prompt 前30%写入 `[HIGH_KEY_LUMINANCE_LOCK]`。
3. 为每个允许变色元素建立元素级明亮色板，写明原色、目标色、明度角色与禁止色。
4. 写入 `[PRODUCT_LIGHTING_LOCK]`，产品只接受自然光影融合，不接受环境染色。
5. 成图后运行分区亮度QA。
6. 区分轻微偏差、需人工复核与确认的系统性压暗；不得用竞品包装与目标包装的固有色差自动触发付费重试。

## 高调亮度锁固定意图

`[HIGH_KEY_LUMINANCE_LOCK] 图片2是整体曝光、白场亮度、产品高光面积、阴影强度和色块明度的唯一参考。保持高调商业棚拍效果；原图高明度区域继续高明度。禁止灰蓝蒙层、暗角、低曝光、全局冷暖滤镜、烟雾压灰和用深色营造所谓科技感。生成图各主要区域不得比图片2明显变暗。`

## 元素级明亮色板

禁止只写“颜色与产品适配”。每个可变元素必须明确：

- 红色标题/横幅：亮正红、高光红或红白渐变；禁止酒红、暗红、棕红。
- 蓝色标题/横幅：亮蓝、电光蓝、天蓝或蓝白渐变；禁止藏蓝、墨蓝、大面积深蓝。
- 徽章：主体保持亮色和可见高光，深色仅作细描边；禁止整枚徽章暗化。
- 底栏：保持参考图原明度角色与渐变停靠点，不得扩大暗色面积。
- 黑字：可保留必要黑色，但不得同时把相邻红蓝强调字、横幅和底栏一起压暗。

## 产品光影锁固定意图

`[PRODUCT_LIGHTING_LOCK] 产品包装保持图片1原色与材质，不受背景或环境光统一染色。白色/透明区域保持洁白通透和宽幅柔和高光；暗部面积不得增加。瓶盖只允许浅灰白塑形，禁止深灰金属渐变。接触阴影柔软、浅淡、窄范围；轮廓光与参考一致，不得以重阴影制造立体感。`

## 色相＋明度保持

每个可变元素记录：`元素ID / 原色 / 目标产品取样色 / hue_family / luminance_role / saturation_role / 最终色 / 对比判断`。

- 背景保持浅、亮、通透；原图高明度区域继续高明度，不因目标包装含深色而整体压暗。
- 色相可映射到目标产品色板，但高/中/低明度关系、前后层次和局部对比必须保持。
- 红色使用亮红、高饱和红或高光红，不使用暗红、酒红；蓝色使用亮蓝、天蓝、电光蓝或蓝白渐变，不使用大面积藏蓝、暗蓝；其他色相同理使用明亮阶。
- 深色只允许小面积用于细描边、分隔和必要对比，不得成为背景、横幅、底栏、徽章或勋章的主体色。
- 禁止全画面统一冷色/暖色滤镜、降低曝光或把人物与产品一起染色。
- 禁止为了目标产品蓝白红色板而把竞品背景整体高饱和蓝化；若适配会吞没黑色结构线、深色仪器框、管线路径或原有冷暖对比，关键结构原色和可辨识度优先。

## 标题醒目处理

- 主标题和次标题优先亮色，保持原字体、字号、换行、坐标和字重。
- 为适配背景，可沿用或适度增强原图已有的亮色/白色描边、外发光、荧光边缘、电镀高光或闪光质感。
- 同一标题最多使用一种主强化方式加一种必要描边，不叠加多种互相冲突的光效；保持高质感和可读性。
- 浅背景若使用白色标题，必须增加亮蓝、亮红或高对比细描边；不得用大面积暗色填充解决对比。

## 视觉优先级

1. 最高级：主产品、主标题、次标题。必须清晰、精致、高对比，承担第一至第三视觉落点。
2. 次级：横幅、徽章、勋章。保持明亮易读，但饱和度、面积高光和对比不得超过最高级内容。
3. 最后：背景。保持浅亮与空间感，避免大面积高饱和、复杂纹理或强高光抢主体。

最终验收目标：整体明亮通透；最高级内容高质感且突出；次级信息清楚；背景退后承托。

## QA

以下任一情况为 `REJECTED`：产品或人物被统一调色；画面整体比参考明显压暗；背景、横幅或徽章以大面积暗红/暗蓝为主；主标题或次标题对比不足；次级元素抢过产品和标题；颜色映射无法追溯到产品色板。轻微HEX偏差但仍属于目标亮色家族且层级正确，记 `NOTE`。

分区量化采用分级门槛：

- `global / background mean_luma`下降5%–10%：`NOTE`；`global`超过10%：`REVIEW_REQUIRED`；`background`超过10%时，只有参考HIGH/MID实际降为LOW才`REJECTED`，仍处于同一亮度等级时为`REVIEW_REQUIRED`。
- `product mean_luma`下降超过7%、`dark_ratio`增加超过0.03或`p90_luma`下降超过0.05：单项为`NOTE`。只有平均下降超过12%，且暗像素增加超过0.06或P90下降超过0.08，才为`REVIEW_REQUIRED`。
- `headline dark_ratio`增加超过0.08、`banner / badge / bottom_bar`增加超过0.05：`NOTE`；分别超过0.12和0.10：`REVIEW_REQUIRED`。
- `headline / banner / badge / bottom_bar`由HIGH/MID降为LOW：`REVIEW_REQUIRED`，不得仅据固定框自动拒绝；用户确认删除、替换或改写后不再保持原语义的区域只作提示。

`REVIEW_REQUIRED`必须对照图片1判断目标包装是否保持原色与材质，并检查是否存在统一灰蓝染色、高光丢失或接触阴影异常。确认只是目标包装固有深色、合法色板映射或轻微坐标漂移时降为`NOTE`。参考图本身为低调暗场时，不强行提亮到高调白场，但仍保持各分区相对明度角色与动态范围。单纯亮度硬失败每任务最多自动重试1次。

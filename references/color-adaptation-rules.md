# 产品配色自适应规则

目标是在不改变版式和内容的前提下，让画外字体与底部框体和 `ProductImage` 的产品包装形成统一视觉系统。

## 1. 绝对锁定

不得改变：

- 文案、数字、标点、换行、字体类别、字号、字重、字距、对齐和阅读顺序。
- 所有元素的位置、占比、边界、层级、间距和遮挡。
- 容器/框体的形状、尺寸、圆角、分区、描边宽度、阴影方向和渐变结构。
- 产品数量、外形、材质、透明度、包装、Logo、印刷文字和产品原始颜色。
- 背景、人物/动物、道具、图标、特效、光影和镜头。

## 2. 唯一允许变更

- 画外文字：填充色、描边色、阴影色。
- 底部框体/通栏：填充色、边框色。
- 原底框已有渐变时：可替换渐变色值，但必须保持原方向、停靠点数量、分区和结构。

其他任何颜色不得调整。

## 3. 产品色板提取

从产品包装可见区域提取：

1. 主色：标签或包装覆盖面积最大、最能代表产品身份的颜色。
2. 辅色：与主色共同构成品牌识别的第二颜色。
3. 强调色：Logo、功能条、角标或关键图案的小面积高饱和色。
4. 中性色：包装中的白、黑、灰或深色文字。

透明瓶和白底产品不得把透明、白底或环境色误当主色；优先从标签、瓶盖、Logo和主图案取色。每个色值记录来源区域、HEX、覆盖比例与置信度。

## 4. 映射顺序

1. 主标题填充：优先产品主色。
2. 主标题描边/阴影：优先产品深色、中性色或主色的深阶，确保局部背景上清晰。
3. 副标题与标签：按层级使用产品辅色或高对比中性色。
4. 底部主通栏：优先产品主色；多分区通栏依次使用主色、辅色、强调色。
5. CTA 或重点角标：优先产品强调色；若强调色与背景对比不足，使用高对比中性色文字。

不得机械地把所有区域改成同一个颜色。保留目标图原有的主次层级、冷暖关系和促销节奏，只替换颜色家族。

## 5. 结构保持

- 原文字为纯色则保持纯色，不新增渐变。
- 原文字为渐变则保持渐变方向、层数和高光逻辑，仅替换色值。
- 原底框为单色则保持单色；原底框为多分区或渐变则保持原分区和渐变结构。
- 不新增框体、描边、投影、徽章或装饰，不删除原有结构。

## 6. 对比与适配

- 大标题和核心数字必须一眼可读；文字不得与局部背景或底框融为一体。
- 深背景使用产品浅色/白色文字并配产品深色描边；浅背景使用产品主色/深色文字。
- 产品主色与背景接近时，使用产品辅色或深阶做文字，主色转用于描边或底框。
- 产品与底框相邻时保留明度差和边界，不让产品轮廓被同色底框吞没。

## 7. 记录与 QA

每个任务记录：

`元素ID / 原目标色 / 产品取样来源 / 产品取样HEX / 最终映射HEX / 文字或框体属性 / 对比判断 / 是否越界`

出现下列任一情况即 `REJECTED`：

- 产品或包装被调色。
- 排版、文案、字体样式、界面结构、框体形状或场景发生变化。
- 非画外字体/底部框体被改色。
- 核心文字对比不足。
- 映射色无法追溯到产品色板。

配色重试只能修改颜色映射 Prompt 片段，禁止重写已正确的文字、构图、产品或场景。

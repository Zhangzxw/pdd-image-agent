# 竞品视觉诊断闭环

## 目的与边界

以资深全品类电商视觉分析师视角工作，但角色说明只用于内部分析，不得进入即梦 Prompt。分析必须覆盖美妆护肤、食品饮料、3C、服饰鞋包、家居日用、母婴宠物、保健品等不同类目的实际视觉逻辑；不得把护肤品规则机械套用到其他品类。

每个结论必须指向图中具体元素、区域、文字、颜色、占比、人物、道具或光影。禁止只写“更高级”“更专业”“更抓眼”等无证据判断。

明确区分三类对象：

1. `competitor_visible_fact`：图片2可直接观察到的事实。
2. `target_identity_constraint`：图片1及详情图可确认的产品事实与不可迁移内容。
3. `planned_replica_strategy`：生成前拟采用的复刻方案；此时不得把尚未生成的图片写成实际结果。

生成后再建立 `actual_replica_observation`，把真实成图与图片2、图片1逐项对照。不得用生成前推测替代生成后观察。

## A. 生成前竞争视觉策略

在向用户汇总冲突映射之前，内部完成以下四部分，并写入任务分析记录。

### 1. 包装风格定调

- 为竞品图选择一个主风格标签，必要时增加一个辅助标签，例如德系药妆、日系极简、国潮、科技极客、轻奢、市井烟火、院线专业、成分党；标签必须由可见证据支持。
- 记录色彩体系、商品主体呈现方式、信任背书来源。分别指出对应元素及坐标区域。
- 判断 `planned_replica_strategy` 相对竞品可能发生的风格偏移：保持、可控升级、降级风险或品类错位，并说明具体原因。
- 为拟生成图给出一个明确风格标签；不得为了“升级”改变竞品构图骨架或虚构目标产品事实。
- 判定 `pose_complexity`：`LOW`（正面/近正面）、`MEDIUM`（明显平面倾斜或轻透视）、`HIGH`（横置、倾倒、开瓶、强俯仰/偏航、透视缩短、复杂遮挡）。HIGH 自动启用 `controlled_3d_pose + COMPOSITION_DOMINANT`。

### 2. 卖点与第一眼信息

- 建立 `attention_path_0_3s`：0.3秒第一眼、第二眼、第三眼分别落在哪个具体元素。
- 确认最强卖点钩子属于数据锚点、功效承诺、品牌背书、价格暗示、场景代入或权威认证中的哪类；记录原文字或视觉符号。
- 建立 `hook_retention_plan`：哪些钩子原样保留、因冲突替换、必须删除、由目标产品新增。新增钩子必须可由目标产品确认。
- 预测手机缩略图状态下最抓眼的3个元素，并判断是否与核心卖点一致。若不一致，优先通过主体占比、标题对比和现有版式层级校正，不新增无依据文案。

### 3. 生成前细节风险矩阵

逐项记录 `expected_status / evidence / risk / prompt_action`：

- 色彩统一性：主色数量、辅助色、是否打架。
- 产品主体：材质、光泽、角度、大小占比。
- 姿态与视觉质量：长轴端点、瓶口/底端锚点、俯仰/偏航/滚转、轮廓面积、高对比标签面积和亮暗质量中心。
- 文字排版：字号层级、字重、手机端可读性。
- 信任元素：徽章、证书、认证、Logo、产地标识。
- 背景氛围：场景感、专业感、高端感、生活感。
- 人物与道具：手部姿势、使用场景、光影方向、辅助道具。
- 专业符号与数据可视化：成分表、参数、分子式、检测报告。
- 关键场景结构：分隔线、框架、仪器底座、管线路径、图标、平台和承托物是否完整。

此处状态使用 `EXPECTED_KEEP / EXPECTED_CHANGE / HIGH_RISK`，不得提前使用生成后才成立的✅⚠️❌。

### 4. 优化优先级

输出按以下层级排序的 `optimization_priority_queue`：

- `P0 身份与事实`：产品包装、Logo、品名、规格、认证、浓度、第三方品牌冲突。
- `P1 第一眼商业信息`：产品占比、主标题/次标题、0.3秒阅读路径、最强卖点钩子和手机缩略图识别。
- `P2 构图与质感`：锚线、留白、层级、材质、光影、人物/道具、KEY邻接细节。
- `P3 装饰一致性`：徽章细节、微型英文、非核心纹理和小型装饰。

只有不改变用户确认文案、产品事实和竞品构图骨架的优化才可自动进入 Prompt。涉及替换、删除、认证、功效、规格、赠品或店铺事实的内容仍必须进入唯一一次用户确认。

## B. 生成后实际对比复盘

候选图下载后，对真实成图执行同一框架：

1. `style_outcome`：竞品风格、实际复刻图风格标签、偏移证据，并判定 `保持 / 可控升级 / 降级 / 品类错位`。
2. `attention_outcome`：实际0.3秒第一、第二、第三视觉落点；实际缩略图最抓眼3元素；是否与核心卖点一致。
3. `hook_outcome`：保留、丢失、错写、新增的卖点钩子。
4. `detail_scorecard`：对色彩、主体、文字、信任元素、背景、人物/道具、专业符号逐项标注：
   - `✅`：保留到位。
   - `⚠️`：有偏差但未破坏核心商业信息。
   - `❌`：丢失、错误或造成身份/构图/核心信息失败。
5. `next_action`：按P0–P3给出下一步；只把符合硬失败定义的项目触发付费重试。

## 与宽容 QA 的关系

竞争视觉诊断提供商业解释，不取代宽容 QA：

- P0失败、构图骨架改变、核心文案或最强钩子错漏、0.3秒第一落点被错误辅助元素夺走、手机缩略图无法识别主产品/主标题，属于硬失败候选；按 `qa-checklist.md` 最终判定。
- P2/P3轻微偏差通常记 `NOTE`，不得仅因“没有参考图高级”自动付费重试。
- “升级/降级”必须相对于竞品原本商业意图、目标产品事实和用户确认方案判断，不以分析者个人审美替代证据。

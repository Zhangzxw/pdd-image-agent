# 双参考宽容 QA

同时对照产品母版与竞品构图图。像素测量用于诊断和下一轮引导，不把小到中等坐标、字号、留白、边界、间隙和徽章尺寸差异单独判为失败。

## 硬失败

- 产品换色、换包装、换Logo、换品名/规格，或显著竞品包装回流。
- 新增 `allowed_pack_elements` 之外的包装圆章、认证、文字、图标、色块或组件；`protected_empty_zones` 被填入。
- 商品数量错误、多件不同款、严重拉伸弯曲、未授权结构发明或核心产品缺失。受控三维姿态本身不判失败。
- 对照图片1，整体宽高比、瓶盖/泵头宽高比、瓶颈高度、肩部最大宽度或左右对称性、液位、标签四边、瓶底厚度出现肉眼明显漂移；原本平行的正面边线变成明显梯形收敛。
- 姿态类别错误；长轴方向落入错误象限或偏差约大于15°；瓶口/底端锚点、关键交点或遮挡关系明显错误。
- 视觉质量偏移约大于20%并改变画面平衡，或KEY分隔线、框架、管线、仪器底座、图标等关键场景结构完全缺失。
- 用户确认的主标题、核心数字、替换、删除或必须保留文案明显错漏、串位或不可读。
- 删除项留下空框、残字、伪文字或替代元素。
- 构图骨架改变：商品组跨到错误半区、标题与商品主次颠倒、底栏失去原主要形态、人物或关键场景完全缺失。
- KEY邻接细节完全缺失、手部明显畸形，或关键元素遮挡Logo、品名和规格。
- 产品被统一滤镜染色，或画面整体明显压暗，使主产品、主标题和次标题不再突出。
- 背景、横幅、徽章大面积使用暗红、暗蓝等深色主体色，违背明亮色相与视觉层级。
- 分区亮度检测确认系统性压暗：背景`mean_luma`下降超过10%且由HIGH/MID降为LOW；或人工复核确认统一灰蓝染色、高光明显丢失、重阴影导致核心内容不突出。产品区不得因与竞品包装的固有色差单独判硬失败。
- 产品白色/透明区出现统一灰蓝染色、瓶盖深灰金属化、接触阴影明显加宽加深。标题、横幅、徽章或底栏由HIGH/MID降为LOW时先进入人工复核；用户确认删除、替换或改写后不再保持原语义的固定区域只作提示。

## NOTE

- 商品仍在正确区域时的小到中等占比、留白、边界、间隙、重叠、底栏高度、徽章尺寸或字号差异。
- 为保护文字而自然降低二维倾角。
- 长轴约6°–15°偏差或视觉质量约10%–20%偏差，但未改变主要构图与第一眼层级。
- 包装微型字和画外非核心微型英文轻微近似。
- 明亮色相HEX略有偏差，但仍属于目标亮色家族、层级正确且易读。

## 判定与重试

使用 `PASSED / PASSED_WITH_NOTES / REVIEW_REQUIRED / REJECTED`。只有人工确认的硬失败重试，每任务最多2次。重试完整重申产品身份、包装拓扑、构图、版式、删除闭环与明亮视觉层级，并将失败项放在 Prompt 前30%；NOTE及未经确认的REVIEW_REQUIRED不付费重试。

候选图下载后先运行：

```powershell
python "<SKILL_DIR>\scripts\luminance_qa.py" --reference "<图片2>" --candidate "<候选图>" --regions "<luminance-regions.json>" --output "<luminance-qa.json>"
```

提交首轮生成前先验证所用Python可以导入Pillow。脚本退出码`0`表示通过或带提示，`2`表示量化拒绝，`3`表示人工复核，`4`表示依赖缺失。脚本只负责亮度证据，不替代产品身份、构图和文案人工QA。`REVIEW_REQUIRED`必须同时对照图片1排除包装固有色差、合法配色映射与轻微区域错位；未经确认不得自动重试。缺少分区文件时仅检测全图，必须补做背景、产品及实际存在的标题/横幅/徽章/底栏人工检查。

亮度专项重试必须只强化失败项，同时完整重申已正确的构图和产品身份：删除灰蓝蒙层、暗角、低曝光、重阴影、酒红和藏蓝主体；恢复参考白场、宽幅产品高光、浅灰瓶盖塑形、柔软窄接触阴影、亮正红与亮蓝。不得用全局提亮导致包装过曝或黑色结构线消失。单纯亮度失败最多自动重试1次；`NOTE`和未确认的`REVIEW_REQUIRED`不付费重试。

产品几何形变使用固定重试链：

1. 首轮若为 `controlled_3d_pose` 且出现形变，第一次重试改为 `rigid_2d`，禁止三维透视，并逐项写入目标整体、瓶盖、瓶颈、肩部、标签、液位和瓶底比例。
2. 若第一次重试仍出现梯形收敛或比例漂移，第二次重试把 `[ZERO_DEFORMATION_PRODUCT_LOCK]` 放在最高优先级，把倾角降至约5°–10°；必要时放弃精确参考倾角，保持正面平视。
3. 达到最多2次重试后仍形变，停止付费重试并标记 `REJECTED`；不得把明显形变降级为NOTE。

## 竞争视觉复盘

每次候选图必须按 [competitive-visual-analysis.md](competitive-visual-analysis.md) 补充：实际风格标签与偏移、实际0.3秒前三视觉落点、手机缩略图最抓眼3元素、卖点钩子的保留/丢失/错写/新增，以及色彩、产品主体、文字、信任元素、背景、人物/道具、专业符号七项`✅ / ⚠️ / ❌`表。

若主产品或主标题不再是前三视觉落点、最强卖点钩子明显错漏，或手机缩略图无法识别主产品/主标题，按硬失败候选复核；只有确实破坏核心商业信息时判`REJECTED`。风格或质感轻微偏差不单独触发重试。

## 执行记录

逐项记录产品身份、包装白名单/空区、几何保真指标、构图骨架、`pose_mode`、长轴与端点锚点、视觉质量、KEY场景结构、核心文案、删除项、KEY邻接细节、手部、明亮度、视觉层级、字体、submit_id、积分和选中 attempt。候选图必须同时与目标产品和竞品并排核验；先看目标产品几何，再看竞品构图，不得只看单图主观判断。

# 生成结果分级校验

QA 必须同时对照目标效果图与产品事实图，并提供可见证据。

## 阻断项

1. 商品结构：数量错误、额外商品或缺失；产品明显过小/过大、位置跨越主要构图区，或二维倾斜方向与目标图相反/目标明显斜放但结果完全直立，导致主体关系明显偏离。轻微角度、占比、间距和位置差异不作为阻断项。
2. 产品身份锁：产品轮廓、真实宽高比或结构发生拉伸、压缩、弯曲、透视扭曲；出现未经证据支持的侧面、俯视、仰视或三分之二视角；LOGO 轮廓、颜色、位置或比例变形；任一可辨认保护文字错字、漏字、多字、增笔、错位、模糊或出现伪文字；标签边界、材质、源图三维观察视角或清晰度明显错误。整件产品及其原生文字同步进行刚性二维平面旋转不属于视角错误。
3. 核心营销文字：主标题、数量标签、徽章、底部通栏、核心数字出现错字、漏字、多字、数字错误或区域串位。
4. 不可变项：排版、字体样式/字号/字重/换行、界面结构、框体形状/位置、场景、产品数量或产品主图发生变化。
5. 产品颜色：产品本体、包装、Logo或标签颜色被统一调色、换色、偏色或套用目标色滤镜。
6. 限定配色：颜色变化超出画外字体与底部框体；或字体/底框未与产品色板建立明显关系；或对比不足导致核心信息难读。
7. 目标视觉：核心构图、场景、光影、主要道具、特效和商业氛围明显缺失或跑偏。
8. 产品邻接细节：`product_adjacent_detail_inventory` 中任一 `KEY` 项完全缺失、位置关系明显错误，或被错误替换为其他材质；例如目标图产品下方有明显绵密泡沫，而结果只有毛巾、阴影或空白。若邻接细节遮挡品牌、品名、规格或导致包装重绘，同样阻断。
9. 主体占比锁：逐件核对顶部、底部、宽度、高度、边界框面积和出框程度，多件商品核对总面积、可见间隙、重叠率与遮挡率。满版任务中商品仍明显偏小、没有贯穿目标主体区、双商品分散或间隙明显超过2%且参考图并非如此，即 `REJECTED`。轻微面积差异不阻断，但不得用拉伸或三维重建换取占比。
10. 版式回归锁：产品大小/位置重试后，重新核对每个标题的填充、描边、阴影、字体、换行，标签底框形状与颜色、图标类型与数量、全部宣传文案和底部框体。产品占比已修复但任一原本正确项走样、缺失或改色，仍为 `REJECTED`。
11. 构图锁：商品组、标题区、徽章区、人物/道具区和底栏区的视觉质量、留白、锚线、前后层级、遮挡关系或阅读顺序明显偏离；或用中心、对称、极简留白等通用构图替代目标实际构图。
12. 光影边界：产品被场景统一染色或套滤镜，包装底色、Logo颜色、印刷内容、标签边界、材质本色或透明度发生变化，或强高光洗掉核心文字。
13. 核心可见区：Logo、品名、规格或主图案区被手、泡沫、徽章、强光或其他商品错误遮挡。
14. 多商品一致性：同一画面内的商品出现不同包装、不同颜色、不同Logo、不同品名/规格或不同标签版本。

任一阻断项失败，结论为 `REJECTED`，不得输出最终图。

产品主事实采用分级判定：核心包装结构、Logo、品名、主要参数、净含量、主图案和保护清单中可辨认的文字属于硬约束，错误、变形或模糊即阻断；只有源图中无法可靠辨认的微型印刷文字存在轻微模糊、近似笔画或局部缺失时记为提示项，不得据此无限重试。

姿态采用整体视觉判断，不设置固定角度或像素误差线。只有产品方向、展示大小、主要位置三项中至少两项明显偏离目标图，或单项偏离已破坏核心版式时，才按商品结构阻断；否则进入提示项。不得为了通过姿态检查而接受任何产品失真或文字变形。

`REJECTED` 必须进入自动重试队列；从可见证据提取最小修复集合，只强化失败项。每个任务最多重试2次。每轮都重新执行完整阻断项与提示项检查，不能因为只修改一个问题就跳过其他检查。即使只修复主体占比，新 Prompt 也必须完整重申 `layout_regression_lock`，不得使用“保持上一轮不变”替代。

## 提示项

- 极小包装说明、无法从产品图可靠辨识的微型字；应尽最大程度保持其原位置、行数、颜色和印刷密度，不接受主动改写或虚构为另一段可读内容。
- 不影响产品身份与营销信息读取的轻微装饰差异。
- 非核心背景软装的小范围位置差异。
- 二维倾斜方向正确但幅度略有差异；产品展示大小或位置基本接近，但因保持真实宽高比产生合理差异。
- 为保护包装结构、Logo和文字清晰度而自然降低倾斜程度，且仍保留目标图的主要方向感。
- 映射色与建议 HEX 有小幅偏差，但仍明显属于产品色板且保持良好可读性。
- `SUPPORTING` 或 `MICRO` 邻接细节仍然存在且材质语义正确，但泡孔/水珠/颗粒的数量、密度、形状或精确位置略有差异。

只有提示项时结论为 `PASSED_WITH_NOTES`，允许输出最终图，但必须在 QA 和执行日志中写明差异。所有项一致时为 `PASSED`。

## 执行记录

- 确认输入图片只有产品事实图。
- 确认参数为 `5.0Pro / 1:1 / 2k / 1张`。
- 记录 `submit_id`、状态、积分和下载路径。
- 给出每项 `PASSED / NOTE / REJECTED`、证据、影响与是否重试。
- 逐项核验不可变项矩阵，并核验产品颜色未被改变。
- 逐项核验产品身份保护清单、`[PRODUCT_IDENTITY_LOCK]` 执行结果、LOGO 视觉一致性与可辨认保护文字清晰度。
- 逐项核验 `product_adjacent_detail_inventory`，分别报告 `KEY / SUPPORTING / MICRO` 的存在性、材质语义、位置层级、覆盖程度及是否错误遮挡产品；不得用“场景一致”概括。
- 核验每个字体/底框颜色是否来自记录的产品色板，是否保持清晰对比；不得只写“颜色协调”。
- 核验 `subject_occupancy_lock` 的逐件边界框、高度、面积、出框、双商品间隙/重叠，并报告是否启用满版模式。
- 核验 `composition_lock` 的视觉质量、留白地图、锚线、阅读路径、深度层与遮挡图。
- 核验 `lighting_application_boundary` 和 `core_visibility_zone`。
- 多商品核验 `same_master_product=true`，逐件比较包装身份。
- 核验 `layout_regression_lock` 中标题填充/描边/阴影、标签底框、图标数量、文案、字体和框体在每次尺寸重试后是否完整回归。
- 对重试任务记录 `attempt_index / previous_failure / prompt_delta / submit_id / credit / result / next_action`；最终明确选用的 attempt。

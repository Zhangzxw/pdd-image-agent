# 双参考复刻 Prompt 规则

## 输入权威

- 图片1始终是唯一产品身份母版；图片2提供构图、展示姿态、人物、场景、文字槽位、底栏和阅读顺序，不提供包装事实。
- Prompt 首段必须写 `[DUAL_REFERENCE_AUTHORITY]`。普通正面任务随后写 `[PRODUCT_IDENTITY_LOCK]`；姿态/构图高风险任务随后写 `[COMPOSITION_DOMINANT]`，再用精简身份锁保护包装。
- 产品详情图只供本地核对，不上传。

## 自适应组装顺序

1. 双参考权威声明。
2. 普通正面、近正面或只需平面滚转的任务：产品身份与 `[PRODUCT_GEOMETRY_FIDELITY_LOCK]` 优先；只有真实开瓶、倾倒、明显俯仰/偏航、强透视、可见侧面或复杂遮挡任务才使用构图主导段优先。
3. `[HIGH_KEY_LUMINANCE_LOCK]`：引用图片2的曝光、白场、高光、阴影和分区亮度；高调/浅亮参考图时必须位于前30%。
4. `[PRODUCT_LIGHTING_LOCK]`：包装本色、白色/透明区高光、瓶盖灰阶、接触阴影和禁止环境染色。
5. 在前30%同时写入精简产品身份、几何比例、`pose_mode / product_pose_lock / visual_mass_lock / critical_scene_structure_lock` 与当前最高风险。
6. 主体占比、多商品一致性和核心可见区。
7. KEY邻接细节。
8. 版式回归锁、删除闭环、全部画外文案及元素级明亮色板。
9. 场景、人物、道具和镜头。
10. 字体、视觉优先级、精简竞品排除项和通用负面约束。

Prompt 只含可执行画面指令，禁止混入角色设定、分析步骤、用户确认和QA。产品身份核心段只出现一次；保护文字集中列一次；删除重复形容词和同义负面词。推荐1000–1400个中文字符，硬上限2000。

## 包装拓扑与碰撞闭环

- 正向列出目标包装确实存在的分区、图案、徽章、图标、文字栏和组件。
- 反向列出竞品包装显著但目标不存在的圆章、认证、环形字、图标、色块、瓶盖、泵头和结构。
- 对连续纹理、纯色和空白区写明“保持连续/保持纯净，不得填入竞品元素或新装饰”。
- 多件商品共享完全相同的白名单和空区，不生成不同包装版本。

## 删除闭环

用户要求删除文字、徽章或横幅时，同时写明：删除内容与容器；用原背景、纹理和光影自然补齐；不得留下空框、残字、伪文字或替代元素；不得让相邻元素自动扩张改变版式。

## 构图与占比

写明逐件边界框、顶部/底部、真实宽高比、轮廓与视觉质量面积、长轴端点、瓶口/底端锚点、姿态模式、出框、间隙、重叠、关键交点和层级。构图类型不能替代坐标与锚线。多件商品写 `same_master_product=true`。允许受控三维姿态匹配，但不得为匹配竞品瓶型而拉伸、换包装或重设计目标产品。

当目标和竞品瓶型不同，必须明确写：边界框只约束整件商品等比缩放与平移；保持目标整体宽高比、瓶盖/泵头宽高比、瓶颈高度、肩部宽度和对称、液位、标签四边、瓶底厚度及关键平行线。若姿态冲突，降低二维倾角或接近正面平视，不用三维透视补偿。

## 字体与明亮配色

- 画外字体默认1种、最多2种；首选PDDZHT，失败时使用拼多多正黑体风格粗黑无衬线体。
- 背景保持浅亮；标题使用亮色并按需要使用清晰描边、荧光边缘或电镀高光；横幅与徽章使用亮色系。
- 视觉优先级固定：主产品/主标题/次标题 > 横幅/徽章 > 背景。
- 深色只作小面积描边或分隔；人物、道具、邻接细节和产品包装不得统一染色。
- 生成前为实际存在的 `global / background / product / headline / banner / badge / bottom_bar` 建立分区亮度基准；禁止以“高端、科技、医美、实验室、质感”等风格词覆盖参考图原有高明度白场。
- 每个红蓝文字、横幅、徽章和底栏都要写明亮色主体与禁止暗色，不能用一句“红蓝适配”概括。

## 提交门禁

核对：双参考顺序正确；产品白名单、空区和几何保真锁完整；姿态模式没有把纯二维滚转误判为三维；最高风险已前置；高调参考图的亮度锁与产品光影锁位于前30%；核心文案与删除项全量列出；元素级明亮色板可追溯；生成前竞争视觉策略已完成；P0/P1中不改变事实与构图的安全优化已转成画面指令；UTF-8回读无替换字符；不得出现“类似参考图”“保持其他不变”等弱指令。

竞争视觉分析的角色设定、0.3秒分析步骤、风格评级、✅⚠️❌表格、P0–P3标签和解释性结论不得进入Prompt；只写由其导出的具体坐标、占比、对比、层级、材质和保留/排除要求。

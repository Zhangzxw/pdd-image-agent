# 目标效果图复刻 Prompt 规则

## 组装顺序

将完整分析组装为一条连续中文 Prompt：画布与风格；产品替换、数量与包装锁定；不可变项总锁；全部画外文字；场景道具和特效；产品色板与限定颜色映射；光影镜头材质；强约束和负面约束。

## 单次即梦融合与保真分级

- 只提交一次完整的 Dreamina `image2image` 融合任务来获得每轮候选图；不得把产品抠图、包装覆盖、文字重绘或本地后期合成作为保真手段。
- 产品段首句必须是：“产品外观、核心印刷文字、品牌 Logo、配色与包装结构必须与目标产品图完全一致。”
- 核心硬约束依次写明：包装结构、品牌 Logo、产品名、主要参数、净含量和主包装图案。任何一项不得根据竞品包装推断、替换或重新设计。
- 微型印刷文字使用：“无法逐字辨认的微型印刷说明按输入产品图尽最大程度保留其位置、行数、颜色和印刷密度，不主动改写、不虚构新文字。”不得反复堆叠“所有小字100%正确”等不可验证要求。
- Prompt 总字数不超过 2000 个中文字符；发生超限时优先删除重复形容词和非核心装饰描述，禁止删减产品硬约束、核心画外文案、构图坐标、光影和负面约束。

## 默认复刻规则

- 原样采用目标效果图的促销文案、营销文案、数字、标点和换行，不自动改写卖点。
- 原样采用目标图的数量关系、构图、场景、软装、道具、特效和明暗/冷暖氛围。
- 仅将目标图商品替换为产品事实图中的商品；多件商品从同一输入复制。
- 每段精确文字都使用中文引号；文字多时仍须逐区列出，不得概括为“同参考图”。
- 不得用“类似”“参考原图”“促销感强”等模糊词替代具体位置、颜色、材质和光影。
- 保持每个文字区域的字体类别、字号层级、字重、行数、换行、字距、描边宽度、阴影方向和坐标不变。
- 保持所有框体的形状、位置、尺寸、圆角、分区、层级和渐变方向不变。

## 限定颜色适配

- 先写产品色板：产品包装主色、辅色、强调色、中性色及建议 HEX。
- 再逐 ID 写颜色映射：`原目标色 → 产品取样色 → 最终输出色`。
- 只允许调整画外文字填充/描边/阴影，以及底部框体填充/边框/原有渐变色。
- 标题优先使用产品主色；描边和阴影优先使用产品深色或高对比中性色；底部框体使用产品主色与辅色；CTA 强调区使用产品强调色。
- 原图为纯色则保持纯色；原图已有渐变才允许保留同方向、同层数渐变并替换色值。
- 文字与局部背景必须保持清晰高对比；不能因追求同色而让标题、数字或底栏文字与背景融为一体。
- 禁止调整产品本体、包装、Logo、背景、宠物、人物、道具、图标、特效或非底部框体的颜色。

## 产品强约束

- “产品外观、核心印刷文字、品牌 Logo、配色与包装结构必须与目标产品图完全一致”。
- “所有商品均复制自输入的同一产品图”。
- “大小一致、间距均匀、底部对齐、方向一致，不得增减数量”。
- “产品外形、品牌、产品名、主要参数、净含量、主包装图案和可辨识主印刷信息保持输入产品图一致”。
- “产品本体及包装颜色100%保持输入图，不调色、不换色、不套统一滤镜”。
- “排版、宣传文案、字体样式、界面结构、框体形状、场景和产品主图不得改变；只调整指定文字与底部框体的颜色属性”。
- “无多余产品、无形变、无错误品牌、无核心文案错字、无乱码、无水印、无二维码”。

## 产品保真负面约束

在通用避错后追加：禁止重新设计包装，禁止改变包装结构、比例、开合方式、瓶盖、喷头或配件；禁止替换或扭曲品牌 Logo；禁止改写品名、主要参数、规格、净含量和主包装图案；禁止产品换色、偏色、统一滤镜、材质塑料化或错误透明度；禁止核心汉字乱码、笔画断裂、字符错位、多余笔画和模糊；禁止竞品品牌、包装文字、规格或图案迁移到目标产品。微型印刷文字尽最大程度保持原位置、行数、颜色和印刷密度，不得虚构可读内容。

## 提交前覆盖校验

逐项比对分析文件的元素覆盖表和不可变项矩阵。Prompt 对主体、每个文字区域、Logo、道具、特效、软装、颜色映射、光影、镜头、材质和分辨率均有明确片段，且不存在超出允许范围的改色指令后才允许提交。

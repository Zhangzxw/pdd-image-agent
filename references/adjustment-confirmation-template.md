# 逐图调整方向确认模板

## 目的

把生成前分析压缩成用户可以直接复制、删改和补充的执行清单。该清单是本批唯一一次确认，也是后续 Prompt、QA 和硬失败重试的文案依据。详细坐标、亮度指标、风险矩阵和分析解释保留在内部记录，不进入默认确认消息。

## 固定输出顺序

每张图片都按以下顺序组织；没有对应内容时跳过，不创建空标题：

1. 商品替换：竞品数量、目标产品数量、盒/瓶/管组合、瓶盖或泵头状态、横置/竖置/手持姿态。
2. 第三方元素：品牌、店铺、账号、水印、价格、认证、赠品、规格、浓度、控件和平台标记。
3. 画外文案：标题、副标题、数字、英文、徽章、标签、角标、底栏逐条决策。
4. 人物与道具：人物、手部、动物、器皿、刷子、机械臂、泡沫、水珠、膏体等。
5. 场景与构图：背景、左右/上下分栏、产品位置和数量、文字层级、光影与配色。

## 动作句式

只使用以下短句为主，便于用户原位修改：

- `竞品[商品]替换为[目标产品]；保持[数量、姿态、盖型或组合]。`
- `删除“第三方品牌/账号/价格/认证”。`
- `“原文”修改为“建议文案”。`
- `“原文”保留。`
- `“原文”删除。`
- `保留[人物、道具、背景和构图]。`
- `[背景区域]修改为[具体色相/明度/纹理]；[构图骨架]保留。`

一个动作单独成行。不要写“相关文字全部调整”“删除竞品信息”等无法快速核对的概括句。若同一区域有两行文字，分别引用；若数字与单位属于同一视觉钩子，可在同一行完整引用。

## 用户可见模板

```markdown
已完成图片分析，建议按以下方向调整：

1. 图1：
   竞品双管替换为双支目标产品；保留一前一后的竖向构图。
   删除“竞品品牌”和“第三方账号”。
   “原标题A”修改为“建议标题A”。
   “副标题B”保留。
   “价格/认证C”删除。
   保留人物、台面、水花和底部通栏；背景由深灰修改为明亮暖黄色渐变，左右分栏保留。

2. 图2：
   竞品泵瓶替换为目标软管；恢复目标产品真实白色翻盖。
   “主标题A”保留。
   “徽章B”修改为“目标事实B”。
   删除“第三方店铺”。
   保留手持人物、浴室、泡沫和原文字层级。

其余不与目标产品事实冲突的画外声明、人物、场景、道具、装饰和光影原样保留；不新增价格、认证、赠品、浓度、店铺或未经确认的功效声明。

请直接修改以上清单，或回复“确认”后生成。
```

## 内容选择规则

- 商品替换必须具体到数量与包装组合，例如`一盒一管`、`双管V形`、`一支竖管＋一支横管`；不得只写“换成目标产品”。
- 竞品商品带有目标产品不存在的泵头、喷嘴、滴管、开盖、挤出或盒体时，必须明确恢复目标结构，或把未知结构列为待确认项。
- 第三方品牌、店铺、账号、水印、价格、认证、赠品、竞品规格和浓度必须逐项点名；相同文字在多张图出现时仍按图片分别列出。
- 强卖点、百分比、时效、疗效、认证和价格不得由代理静默保留或改写。先给出基于目标事实的建议，用户可直接覆盖；其最终逐项回复优先。
- 用户已经明确指定某条文案的处理方式时，原样写回清单，不要再次提出不同建议。
- 若用户提供的回复沿用该模板，只把变化部分写入新的冲突映射；未提及内容按当前清单的`保留/删除/修改`状态执行，不追加第二轮确认。

## 禁止的输出方式

- 不用表格：手机端不便逐条编辑。
- 不先输出长篇设计分析再附简表。
- 不使用P0/P1、视觉质量、拓扑锁、luma等内部术语。
- 不用“优化一下”“更高级”“适配产品”等缺少对象和动作的措辞。
- 不把所有图片合并成一组共同文案；每张图片必须能独立执行。
